# Urban Heat Island Mitigation Simulation - Guwahati

## Project Overview

This project focuses on analyzing the Urban Heat Island (UHI) effect in Guwahati city using satellite remote sensing data and geospatial analysis.

The main objective is to identify heat-risk regions by combining:

- Land Surface Temperature (LST)
- Normalized Difference Vegetation Index (NDVI)
- Heat Risk Index
- Grid-based spatial analysis

The generated dataset can be used for future machine learning models and urban heat mitigation planning.

---

# Workflow

## 1. Satellite Data Collection

Satellite data was collected using Google Earth Engine.

Dataset Used:

- Landsat 8 Collection 2 Level 2
- Time Period: January 2025 - December 2025
- Cloud Cover Filter: Less than 20%

---

# 2. Study Area

Location:

Guwahati, Assam, India

The Guwahati city boundary was imported into Google Earth Engine for spatial analysis.

---

# 3. Land Surface Temperature (LST)

Thermal band used:

```
ST_B10
```

Processing steps:

- Extracted thermal information from Landsat imagery
- Converted temperature values into Celsius
- Generated Land Surface Temperature map

Formula:

```
LST = ST_B10 × 0.00341802 + 149 - 273.15
```

Output:

- LST distribution map of Guwahati

---

# 4. Vegetation Analysis (NDVI)

NDVI was calculated using:

```
NDVI = (NIR - RED) / (NIR + RED)
```

Bands used:

- NIR Band: SR_B5
- RED Band: SR_B4

Higher NDVI indicates more vegetation coverage.

---

# 5. Urban Heat Risk Calculation

Heat risk was generated by combining temperature and vegetation information.

Formula:

```
Heat Risk = Normalized LST - Normalized NDVI
```

Interpretation:

- High temperature + low vegetation = High heat risk
- Low temperature + high vegetation = Lower heat risk

---

# 6. Grid Based Spatial Analysis

The Guwahati region was divided into:

```
100m × 100m Grid Cells
```

For each grid cell, features were extracted:

| Feature | Description |
|---------|-------------|
| grid_id | Unique grid identifier |
| LST | Average land surface temperature |
| NDVI | Average vegetation index |
| Heat_Risk | Heat intensity value |

---

# 7. Dataset Generation

The final dataset was exported from Google Earth Engine as:

```
Guwahati_Urban_Heat_Dataset.csv
```

Dataset Features:

```
grid_id
LST
NDVI
Heat_Risk
```

This dataset can be used for:

- Machine Learning models
- Heat prediction
- Urban planning analysis
